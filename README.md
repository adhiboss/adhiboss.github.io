Welcome to the official repository of my personal portfolio space (**adhigowda.me**). This project showcases my journey as a 2nd-year B.Tech Computer Science student specializing in **Cloud & Security** at Jain University, highlighting engineering projects, peer-reviewed research, certifications, and leadership roles.

---

## ⚡ Signature Features
- **"Scroll to Dive into the 'i'" Hero Scene**: Interactive 3D camera zoom scaling 45x directly into the focal dot of the letter 'i' in "Adhi".
- **12 Floating 3D Orbital Nodes**: Domain nodes covering AI, systems, cloud, research, and creative web with real-time mouse perspective tilting.
- **Live Device FPS Benchmark**: Native diagnostic profiler monitoring frame execution rates (60+ FPS) with a toggleable pinned HUD.
- **Zero-FOUC Dual Themes**: Instant switching between **Cosmic Dark** (ambient drifting glows) and **Paper Light** (tactile texture).
- **Direct Collaboration Lead Funnel**: Interactive "+ Add to message" basket generating pre-formatted WhatsApp & Email drafts without forms.
- **Live Real-time Telemetry**: GitHub contribution activity heatmap and Duolingo language learning streak.

## 🛠️ Tech Stack & Architecture
- **Frontend Core**: Semantic HTML5, Vanilla ES6+ JavaScript.
